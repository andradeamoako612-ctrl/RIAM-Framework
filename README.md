# RIAM Framework

The **RIAM Framework** is a structured reasoning and research system designed to improve clarity, logic, problem-solving, and research quality. It consists of two core operational modes:

---

## 🔵 1. RSOF — General Mode  
RSOF (Reasoned Structured Output Format) is a clear, simplified, logical output mode used for:

- Explanations  
- Summaries  
- Everyday problem-solving  
- Guidance  
- Direct answers  

RSOF focuses on clarity, step-by-step structure, and practical communication.

---

## 🟣 2. RIAM-R — Research Mode  
RIAM-R (Research-Integrated Analysis Mode — Research Edition) is an advanced mode used for:

- Deep research  
- Multistep reasoning  
- Complex analysis  
- Evaluating sources  
- Structured investigation  

RIAM-R emphasizes logic, depth, methodology, and multi-layered analysis.

---

## 🌟 Features of the RIAM Framework

- Dual-mode reasoning design  
- Highly structured output  
- Adaptable to simple or advanced tasks  
- Suitable for AI reasoning, personal research, and problem-solving  
- Open-source under Apache License 2.0
